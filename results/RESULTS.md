# Brain Tumor CNN-Mamba — Results

## Overview

This document reports the experimental results obtained from the three models in the project:

1. **Model 1 — Hybrid CNN-Mamba**
2. **Model 2 — U-Net Tumor Segmentation**
3. **Model 3 — Morphology-Aware CNN-Mamba**

The results below are taken from the training, validation, and testing outputs of the project notebook.

---

# Model 1 — Hybrid CNN-Mamba

### Task

Multi-class brain tumor classification.

### Dataset Split

| Split | Samples |
|---|---:|
| Training | 3,500 |
| Validation | 1,000 |
| Testing | 500 |
| **Total** | **5,000** |

### Accuracy

| Split | Accuracy |
|---|---:|
| Training | **86.54%** |
| Validation | **84.80%** |
| Testing | **84.40%** |

### Test Classification Metrics

| Class | Precision | Recall | F1-Score | Support |
|---|---:|---:|---:|---:|
| Glioma | 0.80 | 0.73 | 0.76 | 115 |
| Meningioma | 0.75 | 0.75 | 0.75 | 133 |
| No Tumor | 0.95 | 0.93 | 0.94 | 106 |
| Pituitary | 0.88 | 0.95 | 0.91 | 146 |
| **Weighted Average** | **0.84** | **0.84** | **0.84** | **500** |

### Final Test Result

**Test Accuracy: 84.40%**

Model 1 provides the baseline hybrid CNN-Mamba classification performance.

# Model 2 — U-Net Tumor Segmentation

### Task

Pixel-level tumor segmentation from brain MRI images.

### Training Configuration

- Image size: `224 × 224`
- Batch size: `8`
- Epochs: `20`
- Optimizer: AdamW
- Segmentation objective: Binary Cross-Entropy + Dice-based loss

### Validation and Test Segmentation Metrics

| Metric | Validation | Test |
|---|---:|---:|
| Dice | **0.7816** | **0.7915** |
| IoU | **0.6810** | **0.6917** |

### Test Pixel-Level Metrics

| Metric | Test Score |
|---|---:|
| Dice / F1 Score | **0.8215** |
| IoU | **0.6970** |
| Accuracy | **0.9926** |
| Precision | **0.8412** |
| Recall | **0.8027** |
| Specificity | **0.9967** |

### Pixel Accuracy

The notebook also reports pixel-level accuracy across the segmentation loaders:

| Split | Pixel Accuracy |
|---|---:|
| Training | **99.38%** |
| Validation | **99.34%** |
| Testing | **99.26%** |

> **Note:** Pixel accuracy is very high because the background occupies a large portion of MRI images. Dice and IoU are more informative for evaluating the quality of the tumor-region segmentation.

### Final Test Result

- **Test Dice: 0.7915**
- **Test IoU: 0.6917**

Model 2 provides the tumor masks used by Model 3 for morphology extraction.

# Model 3 — Morphology-Aware CNN-Mamba

### Task

Multi-class brain tumor classification using both deep visual features and tumor morphology.

### Dataset Split

| Split | Samples |
|---|---:|
| Training | 4,000 |
| Validation | 1,000 |
| Testing | 1,000 |
| **Total** | **6,000** |

### Accuracy

| Split | Accuracy |
|---|---:|
| Training | **95.75%** |
| Validation | **92.00%** |
| Testing | **89.50%** |

### Test Classification Metrics

| Class | Precision | Recall | F1-Score | Support |
|---|---:|---:|---:|---:|
| Glioma | 0.96 | 0.78 | 0.86 | 254 |
| Meningioma | 0.82 | 0.88 | 0.85 | 306 |
| Pituitary | 0.97 | 0.96 | 0.97 | 300 |
| No Tumor | 0.83 | 0.99 | 0.90 | 140 |
| **Weighted Average** | **0.90** | **0.90** | **0.89** | **1,000** |

### Overall Metrics

| Metric | Score |
|---|---:|
| Accuracy | **0.8950** |
| Precision | **0.9021** |
| Recall | **0.8950** |
| F1 Score | **0.8949** |

### Morphological Features

Model 3 uses morphology extracted from the tumor mask generated by Model 2:

1. Tumor Area
2. Tumor Perimeter
3. Tumor Width
4. Tumor Height
5. Aspect Ratio
6. Circularity

The morphology features are fused with CNN-Mamba visual features before final classification.

### Final Test Result

**Test Accuracy: 89.50%**

# Model Comparison

| Model | Task | Train Accuracy | Validation Accuracy | Test Accuracy |
|---|---|---:|---:|---:|
| **Model 1 — Hybrid CNN-Mamba** | Classification | 86.54% | 84.80% | **84.40%** |

\* Pixel accuracy. For Model 2, Dice and IoU are the more useful segmentation metrics.

# Model 1 vs Model 3

For the classification task:

| Metric | Model 1 | Model 3 | Improvement |
|---|---:|---:|---:|
| Test Accuracy | 84.40% | **89.50%** | **+5.10 percentage points** |

Model 3 improves over Model 1 by combining CNN-Mamba visual representations with explicit tumor morphology features derived from the segmentation output.

---

# Training Behavior

## Model 1

- Training accuracy: **86.54%**
- Validation accuracy: **84.80%**
- Test accuracy: **84.40%**
- The relatively small train-validation gap indicates that the model does not show severe overfitting.

## Model 2

- Validation Dice: **0.7816**
- Test Dice: **0.7915**
- Validation IoU: **0.6810**
- Test IoU: **0.6917**
- Test segmentation performance is comparable to validation performance.

## Model 3

- Training accuracy: **95.75%**
- Validation accuracy: **92.00%**
- Test accuracy: **89.50%**
- The train-test gap is larger than Model 1, indicating **some degree of overfitting**, although the model still generalizes reasonably well to the held-out test set.

# Key Results

- **Model 1:** 84.40% test classification accuracy.
- **Model 2:** 0.7915 test Dice and 0.6917 test IoU.

## Conclusion

The experimental results show a progression from a baseline **Hybrid CNN-Mamba classifier (Model 1)** to a dedicated **U-Net segmentation model (Model 2)** and finally to the **Morphology-Aware CNN-Mamba classifier (Model 3)**.

Model 3 achieves the highest reported classification accuracy of **89.50%**, while Model 2 provides the tumor segmentation masks required for extracting morphology-aware information.
